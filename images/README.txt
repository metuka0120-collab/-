このフォルダに画像を入れると、まとめ画像の
「背景」や「キャラ画像」として使えます。

■ 使える形式
  png / jpg / gif / webp / avif

■ 入れかた
  1) このフォルダに画像をそのまま置く
       images/うちの子.png     →  「うちの子」として選べます

  2) フォルダで分けてもOK（フォルダ名がグループ名になります）
       images/背景/夜空.jpg     →  「背景」グループの「夜空」

  ※ フォルダを掘れるのは1階層までです。
  ※ ファイル名がそのまま名前になります。日本語のままで大丈夫です。

■ 反映のしかた
  画像を置いたら、まとめ画像の画面にある「↻ 読み込み直す」を押してください。
  アプリを再起動する必要はありません。

■ おすすめのサイズ
  背景     … 1200 × 800 px 以上（横長）
  キャラ画像 … 背景が透明なPNG。高さ 600〜1200px くらい

■ 注意
  ファイル名を変えたり画像を消したりすると、
  それを使っていた設定では表示されなくなります。
