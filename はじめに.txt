==========================================================
 デュエル・マスターズ プレイス 参加型配信 対戦記録ツール
==========================================================

■ 起動のしかた（3ステップ）

 1) Node.js を入れる（初回だけ・すでに入っていれば不要）
      https://nodejs.org/ja  →  「LTS」の方をダウンロードして
      設定は変えずに「次へ」で進めるだけでOKです。

 2) このフォルダの「起動.vbs」をダブルクリック
      黒い画面は出ません。裏で静かに動きます。

 3) ブラウザが開いたら準備完了です
      http://localhost:3000/admin


■ 終わりかた

 対戦記録画面の右上「アプリを終了」ボタンを押してください。
 記録を保存してからアプリが止まります。

 タブを閉じてしまったときは「終了.vbs」をダブルクリックしてください。


■ 今どのバージョンが動いているか

 対戦記録画面の右上（タイトルの横）に v1.1.1 のように出ます。
 新しいZIPに入れ替えたのに表示が変わらないときは、
 前のアプリが動いたままになっています。
 「アプリを終了」で止めてから、新しいフォルダの「起動.vbs」を実行してください。


■ 4つの画面（OBSに入れるサイズつき）

 対戦記録    http://localhost:3000/admin
             対戦を記録する。ふだんはこの画面を開いておきます。

 まとめ画像  http://localhost:3000/summary
             配信後、Xに上げる画像をつくります。

 OBS表示     http://localhost:3000/overlay
             募集状況・対戦相手・ルームID・本日の成績を出す帯。
             → OBSのブラウザソース  幅 500 × 高さ 180
             小さいと感じたら URL の後ろに ?scale=1.5 を付けて、
             幅 750 × 高さ 270 にしてください（1.5倍）。

 実況テロップ http://localhost:3000/ticker
             感想を流す帯。画面の下のラインに置きます。
             → OBSのブラウザソース  幅 1920 × 高さ 60


■ 配信中によく使う操作（対戦記録画面の左上から順に）

 ・ルームID（青い枠のカード）
     ゲームで作ったルームIDを入れて「反映」を押すと、OBS表示画面に出ます。
     「消す」を押すと消えます。入力しただけでは出ません。

 ・ワンコメから取り込む（画面の右上）
     わんコメと連携すると、コメントした人がここに並びます。
     名前とアイコンをそのまま取り込めます。

 ・募集ステータス
     「次の対戦者募集中」「募集ストップ中」「募集終了」を切り替えます。
     押した瞬間にOBSの表示が変わります。
     対戦中も「対戦中」と並んで大きく出たままなので、視聴者に伝わります。
     （募集終了のときは赤で出ます）


■ 深夜まで配信するとき

 標準では深夜0時で「本日の成績」が次の日に切り替わります。
 同じ配信としてまとめたいときは、

   「配信の設定」→「1日の区切り」→ 5時 など

 に変えてください。深夜4:59までが前の日ぶんとして数えられます。
 あとから変えても、過去の記録をまとめ直します。記録は消えません。


■ 保存データ

 data フォルダの中の data.json にすべて入っています。
 バックアップしたいときは、このファイルをコピーしてください。
 消さないかぎり、対戦履歴はずっと貯まり続けます。


■ 自分のスタンプを追加したいとき

 stamps フォルダに画像を入れるだけです。
 くわしくは stamps フォルダの中の README.txt を見てください。


■ まとめ画像に背景やキャラ画像を入れたいとき

 images フォルダに画像を入れるだけです。

   images/うちの子.png      →  キャラ画像として置けます
   images/背景/よぞら.jpg    →  背景として敷けます

 まとめ画像の画面で「背景画像」や「キャラ画像を追加」から選びます。
 キャラ画像は、できあがりの画像の上を直接ドラッグして動かせます。

 画像を入れたら「↻ 画像フォルダを読み込み直す」を押してください。


■ うまくいかないとき

 ・「起動.vbs」をダブルクリックしても何も起こらない
     → 「start.bat」をダブルクリックしてください。
        黒い画面が出て、エラーの内容が分かります。
        （.vbs がメモ帳で開いてしまう場合も start.bat をお使いください）

 ・「npm が見つかりません」と出る
     → Node.js が入っていません。手順1をやり直してください。

 ・「ポート 3000 はすでに使われています」と出る
     → 他のアプリが3000番を使っています。
        黒い画面で次のように打つと3001番で起動します。
          set PORT=3001
          npm start
        そのあとURLの 3000 を 3001 に読み替えてください。

 ・ルームIDがOBSに出ない
     → 入力しただけでは出ません。「反映」ボタンを押してください。

 くわしい説明は README.md に書いてあります。
 （メモ帳で開けます）
