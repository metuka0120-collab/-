# デュエル・マスターズ プレイス 参加型配信 対戦記録ツール

YouTube Live の視聴者参加型対戦で、**対戦履歴を記録してまとめ画像をつくる**ためのローカル用Webアプリです。

- 参加者の受付・整列は **ワンコメなど別のツールに任せる前提**です。このアプリは対戦の記録に専念します。
- インターネット上のサーバーは使いません。**自分のPCの中だけ**で動きます。
- データは JSON ファイル (`data/data.json`) に保存されるので、アプリを終了しても消えません。

| 画面 | URL | 用途 |
| --- | --- | --- |
| 対戦記録 | http://localhost:3000/admin | 対戦の記録・履歴・成績の確認 |
| まとめ画像 | http://localhost:3000/summary | 配信後にSNSへ上げる画像をつくる |
| OBS表示 | http://localhost:3000/overlay | OBSに載せる背景透過のオーバーレイ |

---

## 1. 準備（初回だけ）

### Node.js をインストールする

1. https://nodejs.org/ja を開く
2. **LTS** と書かれた方をダウンロードしてインストール（設定は変えずに「次へ」でOK）
3. インストールできたか確認します。
   - スタートメニューで `PowerShell` と検索して開く
   - 次を入力して Enter

     ```powershell
     node -v
     ```

   - `v20.11.0` のようにバージョンが表示されればOKです。

> Node.js 18 以上が必要です。

---

## 2. 起動する

1. このフォルダを開き、アドレスバーに `powershell` と入力して Enter
   （そのフォルダで PowerShell が開きます）
2. 次の2つを順番に実行します。

```powershell
npm install
```

```powershell
npm start
```

3. 画面に次のように表示されたら起動成功です。

```
==============================================
 デュエル・マスターズ プレイス 配信ツール 起動
==============================================
  対戦記録画面 : http://localhost:3000/admin
  まとめ画像   : http://localhost:3000/summary
  OBS表示画面  : http://localhost:3000/overlay
```

4. ブラウザで **http://localhost:3000/admin** を開いてください。

> **`npm install` は初回だけでOK**です。2回目以降は `npm start` だけで起動できます。
>
> `start.bat` をダブルクリックしても起動できます（`npm install` も自動で行います）。

### 終了するしかた

`npm start` を実行した黒い画面（PowerShell）で **Ctrl + C** を押してください。
データは自動で保存されます。

## 3. 使い方

### はじめに1回だけ

「配信の設定」で **配信タイトル**・**自分の名前**・**自分のデッキ**を入れて保存します。
自分のデッキは対戦を記録するときの初期値になります。デッキを変えたらここを書き換えてください。

### 記録のしかたは2通り

どちらでもOKです。配信のやり方に合う方を使ってください。

#### A. 「対戦中に記録」タブ（OBSに対戦相手を出したいとき）

1. リスナー名と相手のデッキを入れて **対戦開始** を押す
   → OBSのオーバーレイに「リスナー名・デッキ名・本日何戦目か」が**リロードなしで即座に**出ます
2. 対戦が終わったら **勝ち / 負け** を選び、**試合の感想**を書いて **対戦終了して保存**

#### B. 「終わった対戦を記録」タブ（あとからまとめて入れたいとき）

リスナー名・デッキ・勝敗・感想を入れて **この対戦を履歴に追加** を押すだけです。
オーバーレイを使わない場合はこちらだけで完結します。

### 対戦履歴に出るもの

- 何戦目か / WIN・LOSE / リスナー名（アイコン付き）/ 終了時刻
- 相手のデッキ と 自分のデッキ
- 試合の感想
- **スタンプ**（試合の気持ちを一目で分かるように・最大3つ）
- **そのリスナーとの通算成績**（2回目以降の対戦で出ます）

日付ごとにまとまって表示され、上の検索欄で**リスナー名・デッキ名・感想**から探せます。
「勝ちのみ」「負けのみ」での絞り込み、過去の日をふくめた表示もできます。

### 成績の集計

| 場所 | 内容 |
| --- | --- |
| 本日の成績 | 勝利数・敗北数・試合数・勝率（日付が変わると自動で 0 に戻ります） |
| 通算 | 記録している全期間の成績 |
| リスナー別 通算成績 | 誰と何回やって何勝何敗か。使ったデッキも出ます |
| 自分のデッキ別 通算成績 | どのデッキがよく勝てているか |

### そのほかの操作

| やりたいこと | 操作 |
| --- | --- |
| 記録した内容を直す | 履歴の「編集」（名前・デッキ・勝敗・感想すべて直せます） |
| 記録を消す | 履歴の「削除」 |
| 本日の記録を全部消す | 「本日の履歴をリセット」 |
| 対戦を記録せずにやめる | 対戦中の「取り消す」 |

## 4. ワンコメ連携（名前とアイコンの取り込み）

わんコメ（OneComme）が受け取ったコメントから、**リスナー名とアイコン**をワンタッチで取り込めます。
名前を手で打つ必要がなくなり、まとめ画像やOBS表示にアイコンが出せます。

> 参加者の受付・整列（参加型管理）は**わんコメ側の仕事**です。このアプリはそこには触りません。
> 取り込むのは「最近コメントした人の名前とアイコン」だけです。

### 使いかた

1. **わんコメを起動しておく**（配信サイトと接続済みの状態）
2. 対戦記録画面の「ワンコメから取り込む」で **「設定」→「わんコメと連携する」にチェック → 保存して接続**
3. 見出しの横が **● 接続中** になればOK
4. コメントが来ると、その人がアイコン付きで一覧に出ます
5. **「取り込む」を押すと名前が入力欄に入り**、そのまま記録するとアイコンごと残ります

| 表示 | 意味 |
| --- | --- |
| オフ | 連携していません |
| ● 接続中 | わんコメとつながっています |
| × つながっていません | わんコメが起動していないか、接続先が違います |

つながらなくなっても**自動で再接続します**。連携が切れていても、記録機能はふつうに使えます。

### 接続先について

既定は `ws://127.0.0.1:11180/sub` です。わんコメの標準設定ならそのままで動きます。
わんコメ側でポートを変えている場合だけ、設定欄の数字を合わせてください。

### アイコンについて

- 取り込んだアイコンは **自分のPCに保存されます**（`data/icons/`）。配信サイト側で画像が消えても残ります。
- 一度取り込んだリスナーは、**次回から自動でアイコンが付きます**（同じ名前なら手入力でもOK）。
- アイコンは 対戦記録画面 / まとめ画像 / OBS表示 のすべてに出ます。
- 画像として保存するのは、実際に画像だったものだけです（2MBまで）。

## 5. スタンプ（試合の気持ちを残す）

勝敗だけでは伝わらない「熱かった」「くやしい」を、記録と画像に残せます。
1試合につき **最大3つ**まで選べます。

### そのまま使えるスタンプ

何も用意しなくても、絵文字のスタンプが12種類入っています。

🔥 熱かった / 😄 うれしい / 😭 くやしい / 😱 まさか / 👏 ナイス / 🤝 好勝負 /
😂 笑った / 💀 完敗 / ⚡ 一瞬で終了 / 🎯 決まった / 🙏 ありがとう / 🤯 理解不能

### 自分のスタンプ画像を使う

`stamps` フォルダに画像を入れるだけで、そのままスタンプになります。

```
stamps/くやしい.png            →  「くやしい」というスタンプ
stamps/＠参加型/熱戦.png        →  「＠参加型」グループの「熱戦」
```

| 項目 | 内容 |
| --- | --- |
| 使える形式 | png / jpg / gif / webp / svg / apng |
| 名前 | **ファイル名がそのままスタンプ名**になります（日本語のままでOK） |
| フォルダ分け | 1階層までフォルダで分けられます（フォルダ名がグループ名） |
| おすすめサイズ | 正方形 128×128px 前後・背景が透明なPNG |

画像を置いたら、対戦記録画面のスタンプ欄にある **「↻」ボタン** を押すと読み込まれます。
アプリを再起動する必要はありません。

> ファイル名を変えたり画像を消したりすると、そのスタンプを使っていた過去の記録では
> 表示されなくなります（記録そのものは消えません）。

## 6. まとめ画像をつくる（配信後）

**http://localhost:3000/summary** を開くと、その日の対戦結果が1枚の画像になります。
右側に見えているものが、そのまま保存される画像です。

### 保存のしかた

- **「PNG画像として保存」** … `dmps-record-2026-08-29.png` のような名前で保存されます
- **「クリップボードにコピー」** … X（Twitter）の投稿欄で `Ctrl + V` を押すとそのまま貼れます

> スクリーンショットを撮りたい場合は、画面に出ている画像の枠を撮ってください。
> ただし PNG保存のほうが**文字がくっきり**します（画像は横1200pxの高解像度で作られます）。

### 調整できること

| 設定 | 内容 |
| --- | --- |
| どの日の成績にしますか | 本日 / 過去の日 / すべての日（通算） |
| 色 | ダーク（黒背景）/ ライト（白背景） |
| 並べ方 | 自動（13戦以上で2列）/ 1列 / 2列 |
| 試合の感想を入れる | 感想を消すと画像が短くコンパクトになります |
| 自分のデッキを入れる | 1日中同じデッキなら見出しに1回だけ出ます |
| スタンプを入れる | 各試合の右端にスタンプが並びます |
| リスナーのアイコンを入れる | 名前の前に丸いアイコンが入ります（わんコメ連携時） |
| リスナーとの通算成績を入れる | 「通算 2戦 2勝0敗」を各行に足します |
| タイトル / ひとこと | 画像の上と下に入る文字 |

> 対戦数が多い日は **2列**にすると横長になり、SNSでの見え方が良くなります。

## 7. OBS Studio に表示する（使う場合のみ）

対戦相手を画面に出したい場合だけ設定してください。使わなくても記録機能は問題なく動きます。

1. OBS のソース欄の **「＋」→「ブラウザ」** を選ぶ
2. 名前をつけて「OK」
3. 次のように設定する

   | 項目 | 設定値 |
   | --- | --- |
   | URL | `http://localhost:3000/overlay` |
   | 幅 | `480` |
   | 高さ | `140` |
   | ページ非表示時にソースをシャットダウン | **チェックを外す** |
   | 表示されていないときにシーンを非アクティブにする | **チェックを外す** |

4. 「OK」を押して、画面の好きな端にドラッグして配置する

> 背景は透明なので、OBS側でクロマキーなどの設定は必要ありません。
> **アプリ（`npm start`）を先に起動してから** OBS を開いてください。

### 募集ステータス（対戦していないときの表示）

対戦記録画面のいちばん上にある **「募集ステータス」** で、OBSの表示を切り替えられます。
ボタンを押した瞬間に、OBSをリロードせず切り替わります。

| ボタン | OBSに出る文字 | 補足に出る文字 | 色 |
| --- | --- | --- | --- |
| 次の対戦者募集中 | 次の対戦者募集中 | コメントで参加受付中！ | 緑 |
| 募集ストップ中 | 対戦者募集ストップ中 | 待機消化後に再募集します | 黄 |
| 募集終了 | 募集終了 | ご参加ありがとうございました！ | グレー |

対戦を開始している間は、募集ステータスにかかわらず**対戦相手の表示が優先**されます。
対戦が終わると、設定しておいた募集ステータスの表示に戻ります。

> 待機列が溜まって受付を止めたいときは「募集ストップ中」にしてください。
> 待機を消化したら「次の対戦者募集中」に戻します。

### 表示のカスタマイズ（URLの後ろにつけるだけ）

| URL | 表示 |
| --- | --- |
| `http://localhost:3000/overlay` | 標準（対戦者＋本日の成績） |
| `http://localhost:3000/overlay?stats=0` | 本日の成績（勝敗・勝率）を隠す |
| `http://localhost:3000/overlay?idle=hide` | 対戦していないときはオーバーレイ自体を隠す |

## 8. データの保存について

- 保存先： `data/data.json`
- 設定・対戦履歴・現在の対戦が、すべてこの1ファイルに入っています。
- バックアップしたいときは、このファイルをコピーしておいてください。
- 全部リセットしたいときは、アプリを終了してから `data/data.json` を削除してください
  （次の起動時に空の状態で作り直されます）。

### 対戦履歴はずっと貯まります

**自動で消えることはありません。** 記録した対戦はすべて残り続け、
「リスナー別 通算成績」は最初の1戦目から累積して数え続けます。
（「本日の成績」だけは日付で切り替わりますが、過去の記録が消えるわけではありません）

実測した目安は次のとおりです。

| 対戦数 | ファイルの大きさ | 集計にかかる時間 |
| --- | --- | --- |
| 1,000戦 | 約 0.4 MB | 一瞬 |
| 5,000戦（週3配信×8戦で約2年ぶん） | 約 1.9 MB | 約 17 ミリ秒 |
| 100,000戦 | 約 20 MB | 約 70 ミリ秒 |

何年続けても問題ない設計です。試合数が多くなったときのために、次のようにしてあります。

- 対戦履歴の表示は**新しい方から200件まで**（残りは検索で探せます。件数は全件を表示）
- まとめ画像に載る試合は**最大40戦**まで（成績の集計は全件が対象で、「…ほか○戦」と入ります）

**消えるのは、自分で消したときだけ**です。

- 履歴の「削除」を押したとき
- 「本日の履歴をリセット」を押したとき
- `data/data.json` を自分で削除したとき

> リスナーの判定は**名前**で行います（大文字小文字と空白の違いは吸収します）。
> リスナーが名前を変えると別人として数えられます。その場合は過去の記録の「編集」で
> 名前をそろえると、通算成績がひとつにまとまります。

## 9. 困ったときは

| 症状 | 対処 |
| --- | --- |
| `npm : 用語 'npm' は…` と出る | Node.js がインストールされていません。手順1をやり直してください。 |
| `ポート 3000 はすでに使われています` | 他のアプリが3000番を使っています。PowerShell で `$env:PORT=3001; npm start` と実行し、URLの `3000` を `3001` に読み替えてください。 |
| 右上が「× 未接続」 | サーバーが止まっています。PowerShellで `npm start` を実行し直してください（自動で再接続します）。 |
| OBSに何も出ない | アプリを起動してから、OBSのブラウザソースを右クリック →「更新」。 |
| まとめ画像の文字が切れる | 名前やデッキ名が長すぎます。画像では自動で「…」に省略されます。短い表記にすると全部入ります。 |
| クリップボードにコピーできない | ブラウザによっては使えません。「PNG画像として保存」を使ってください。 |
| ワンコメにつながらない | わんコメを起動してから「保存して接続」を押してください。わんコメ側の「設定 > API」でAPIが有効か、ポート番号（既定11180）が合っているかも確認してください。 |
| 取り込んだのにアイコンが出ない | アイコンのダウンロードに数秒かかることがあります。少し待っても出ない場合、配信サイト側が画像を配っていない可能性があります（名前だけは正しく入ります）。 |
| 入れたスタンプ画像が出てこない | スタンプ欄の「↻」ボタンを押してください。それでも出ない場合は、拡張子が png/jpg/gif/webp/svg か、フォルダの階層が深すぎないか確認してください。 |

## 10. 中身（開発者向け）

```
.
├── server.js            Expressサーバー + WebSocket + API
├── lib/
│   ├── store.js         JSONファイルへの保存・集計ロジック
│   ├── stamps.js        スタンプ一覧の作成（絵文字 + stamps フォルダの走査）
│   ├── onecomme.js      わんコメへのWebSocket接続とコメント者の保持
│   └── icons.js         リスナーアイコンのダウンロードと保存
├── public/
│   ├── admin.html/.css/.js     対戦記録画面
│   ├── summary.html/.css/.js   まとめ画像（Canvasで描画してPNG出力）
│   └── overlay.html/.css/.js   OBS表示画面（背景透過）
├── stamps/              スタンプ画像を置くフォルダ（画像を入れるだけで使える）
├── data/
│   ├── data.json        保存データ（初回起動時に自動生成）
│   └── icons/           取り込んだリスナーアイコン（自動生成）
└── package.json
```

### API

| メソッド | パス | 内容 |
| --- | --- | --- |
| GET | `/api/state` | 現在の状態（設定・現在の対戦・履歴・各種集計） |
| PUT | `/api/settings` | 配信タイトル・自分の名前・自分のデッキ |
| POST | `/api/match/start` | 対戦開始 `{ name, deck, myDeck }` |
| PUT | `/api/match` | 対戦中の内容を修正 |
| POST | `/api/match/finish` | 対戦終了 `{ result: "win" \| "lose", comment }` |
| POST | `/api/match/cancel` | 記録せず取り消し |
| POST | `/api/history` | 終わった対戦を直接記録 |
| PUT | `/api/history/:id` | 履歴を編集 |
| DELETE | `/api/history/:id` | 履歴を削除 |
| POST | `/api/history/clear-today` | 本日の履歴をリセット |
| POST | `/api/stamps/reload` | `stamps` フォルダを読み直す |
| POST | `/api/onecomme/reconnect` | わんコメに繋ぎ直す |
| POST | `/api/onecomme/clear` | 取り込んだコメント者の一覧を消す |

状態が変わるたび、`ws://localhost:3000/ws` に接続中のすべての画面へ
`{ "type": "state", "payload": { ... } }` が送られます。3画面ともこれを受け取って再描画します。

まとめ画像は Canvas 2D API だけで描いています（外部ライブラリなし）。
わんコメからのアイコンURLはそのまま保存せず、必ずダウンロードして `/icons/` に置き直します
（配信サイトのURLは消えることがあり、別サイトの画像を混ぜるとまとめ画像をPNGに書き出せなくなるため）。
将来 SQLite に移行する場合は `lib/store.js` を差し替えるだけで済むようにしてあります。
