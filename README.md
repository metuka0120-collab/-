# デュエル・マスターズ プレイス 視聴者参加型 配信ツール

YouTube Live で視聴者参加型対戦をするときに、**参加者と対戦結果を管理する**ためのローカル用Webアプリです。

- インターネット上のサーバーは使いません。**自分のPCの中だけ**で動きます。
- データは JSON ファイル (`data/data.json`) に保存されるので、アプリを終了しても消えません。
- 管理画面での操作は、**OBSの画面をリロードしなくても即時反映**されます（WebSocket同期）。

| 画面 | URL | 用途 |
| --- | --- | --- |
| 管理画面 | http://localhost:3000/admin | 参加者の登録・対戦の開始・勝敗と感想の記録 |
| OBS表示画面 | http://localhost:3000/overlay | OBSに載せる背景透過のオーバーレイ |

---

## 1. 準備（初回だけ）

### Node.js をインストールする

1. https://nodejs.org/ja を開く
2. **LTS** と書かれた方をダウンロードしてインストール（設定は変えずに「次へ」でOK）
3. インストールできたか確認します。
   - スタートメニューで `PowerShell` と検索して開く
   - 次を入力して Enter

     ```powershell
     node -v
     ```

   - `v20.11.0` のようにバージョンが表示されればOKです。

> Node.js 18 以上が必要です。

---

## 2. 起動する

### 手順（PowerShell を使う場合）

1. このフォルダを開き、アドレスバーに `powershell` と入力して Enter
   （そのフォルダで PowerShell が開きます）
2. 次の2つを順番に実行します。

```powershell
npm install
```

```powershell
npm start
```

3. 画面に次のように表示されたら起動成功です。

```
==============================================
 デュエル・マスターズ プレイス 配信ツール 起動
==============================================
  管理画面    : http://localhost:3000/admin
  OBS表示画面 : http://localhost:3000/overlay
```

4. ブラウザで **http://localhost:3000/admin** を開いてください。

> **`npm install` は初回だけでOK**です。2回目以降は `npm start` だけで起動できます。
>
> `start.bat` をダブルクリックしても起動できます（`npm install` も自動で行います）。

### 終了するしかた

`npm start` を実行した黒い画面（PowerShell）で **Ctrl + C** を押してください。
データは自動で保存されます。

---

## 3. OBS Studio に表示する

1. OBS のソース欄の **「＋」→「ブラウザ」** を選ぶ
2. 名前をつけて「OK」
3. 次のように設定する

   | 項目 | 設定値 |
   | --- | --- |
   | URL | `http://localhost:3000/overlay` |
   | 幅 | `480` |
   | 高さ | `140` |
   | ページ非表示時にソースをシャットダウン | **チェックを外す** |
   | 表示されていないときにシーンを非アクティブにする | **チェックを外す** |

4. 「OK」を押して、画面の好きな端にドラッグして配置する

> 背景は透明になっているので、OBS側でクロマキーなどの設定は必要ありません。
> **アプリ（`npm start`）を先に起動してから** OBS を開いてください。
> もし何も表示されないときは、ブラウザソースを右クリック →「更新」で直ります。

### 表示のカスタマイズ（URLの後ろにつけるだけ）

| URL | 表示 |
| --- | --- |
| `http://localhost:3000/overlay` | 標準（対戦者＋本日の成績。対戦していないときは「募集中」表示） |
| `http://localhost:3000/overlay?stats=0` | 本日の成績（勝敗・勝率）を隠す |
| `http://localhost:3000/overlay?idle=hide` | 対戦していないときはオーバーレイ自体を隠す |
| `http://localhost:3000/overlay?stats=0&idle=hide` | 両方を組み合わせる |

## 4. 使い方（配信中の流れ）

1. **参加者を登録する**
   管理画面の「参加者を登録」に *リスナー名* と *使用デッキ名* を入れて「待機列に追加」。
   → 「参加待機列」に並びます。

2. **対戦を始める**
   待機列の「対戦開始」を押す。
   → その人が「現在の対戦者」になり、**OBSのオーバーレイに即座に表示**されます。
   （リスナー名・デッキ名・本日何戦目か）

3. **対戦が終わったら**
   「勝ち」か「負け」を選び、「試合の感想」を書いて「対戦終了して履歴に保存」を押す。
   → 対戦履歴に移り、「本日の成績」（勝利数・敗北数・勝率）が自動で更新されます。

4. 1〜3 を繰り返します。

### そのほかの操作

| やりたいこと | 操作 |
| --- | --- |
| 参加者の名前・デッキを直す | 待機列の「編集」 |
| 参加者を消す | 待機列の「削除」 |
| 並び順を変える | 待機列の「▲」「▼」 |
| 対戦を記録せずにやめる | 現在の対戦者の「待機列に戻す」 |
| 記録した勝敗や感想を直す | 対戦履歴の「編集」 |
| 記録を消す | 対戦履歴の「削除」 |
| 本日の記録を全部消す | 「本日の履歴をリセット」 |

> 「本日の成績」は日付が変わると自動的に 0 に戻ります（前日の履歴は残ります）。
> 対戦中に別の人の「対戦開始」を押すと、それまでの対戦者は待機列の先頭に戻ります。

---

## 5. データの保存について

- 保存先： `data/data.json`
- 参加待機列・現在の対戦者・対戦履歴がすべてこの1ファイルに入っています。
- バックアップしたいときは、このファイルをコピーしておいてください。
- 全部リセットしたいときは、アプリを終了してから `data/data.json` を削除してください
  （次の起動時に空の状態で作り直されます）。

## 6. 困ったときは

| 症状 | 対処 |
| --- | --- |
| `npm : 用語 'npm' は…` と出る | Node.js がインストールされていません。手順1をやり直してください。 |
| `ポート 3000 はすでに使われています` | 他のアプリが3000番を使っています。PowerShell で `$env:PORT=3001; npm start` と実行し、URLの `3000` を `3001` に読み替えてください。 |
| 管理画面右上が「× 未接続」 | サーバーが止まっています。PowerShellで `npm start` を実行し直してください（自動で再接続します）。 |
| OBSに何も出ない | アプリを起動してから、OBSのブラウザソースを右クリック →「更新」。 |
| OBSの表示が切れる | ブラウザソースの「幅」を広げてください（480〜560くらい）。 |
| 文字が小さい／大きい | ブラウザソースの「カスタムCSS」ではなく、OBS上でソースの角をドラッグして拡大縮小するのが簡単です。 |

## 7. 中身（開発者向け）

```
.
├── server.js            Expressサーバー + WebSocket + API
├── lib/
│   └── store.js         JSONファイルへの保存・集計ロジック
├── public/
│   ├── admin.html/.css/.js     管理画面
│   └── overlay.html/.css/.js   OBS表示画面（背景透過）
├── data/
│   └── data.json        保存データ（初回起動時に自動生成）
└── package.json
```

### API

| メソッド | パス | 内容 |
| --- | --- | --- |
| GET | `/api/state` | 現在の状態（待機列・現在の対戦者・履歴・本日の成績） |
| POST | `/api/participants` | 参加者を追加 `{ name, deck }` |
| PUT | `/api/participants/:id` | 参加者を編集 `{ name, deck }` |
| DELETE | `/api/participants/:id` | 参加者を削除 |
| POST | `/api/participants/:id/move` | 並び替え `{ direction: "up" \| "down" }` |
| POST | `/api/participants/:id/start` | 対戦開始 |
| POST | `/api/current/finish` | 対戦終了 `{ result: "win" \| "lose", comment }` |
| POST | `/api/current/cancel` | 対戦を記録せず中止 |
| PUT | `/api/history/:id` | 履歴を編集 |
| DELETE | `/api/history/:id` | 履歴を削除 |
| POST | `/api/history/clear-today` | 本日の履歴をリセット |

状態が変わるたび、`ws://localhost:3000/ws` に接続中のすべての画面へ
`{ "type": "state", "payload": { ... } }` が送られます。管理画面もOBS表示画面もこれを受け取って再描画します。

将来 SQLite に移行する場合は `lib/store.js` を差し替えるだけで済むようにしてあります。
